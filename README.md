# Folder Limit Enhanced

Obsidian標準のファイルエクスプローラーで、フォルダの直下にあるファイルを初期状態では20件まで表示します。21件以上あるフォルダには、末尾に `▼ 残り○件を表示（Projects直下）` のようなボタンが現れます。クリックで全件表示に切り替わり、末尾の `▲ 20件表示に戻す（Projects直下）` でもとの件数に戻せます。Tabでボタンに移動し、EnterまたはSpaceでも操作できます。

サブフォルダは件数に含まれず、同じ上限が各サブフォルダに個別に適用されます。Obsidianが表示するファイルは拡張子を問わず数えます。Vaultのルートも同じ扱いです。

フォルダ名の横には、Vaultが認識するファイル数が表示されます。`21 / 43 · 2フォルダ` は、直下に21ファイル、配下すべてで43ファイル、サブフォルダが2個あることを示します。サブフォルダがない場合や「サブフォルダの件数も併記」がオフの場合は直下のファイル数だけを表示します。20件に省略中のボタンには、そのフォルダの一覧で表示できる残り件数が出ます。標準のフォルダ開閉や全件表示への切り替えでバッジの総数は変わりません。

## インストール

対象はデスクトップ版Obsidian 1.15.1以降です。

1. 元の **Folder Limit** を使用中の場合は、Obsidianの「設定」→「コミュニティプラグイン」で無効にします。
2. Vaultの設定フォルダ（通常は `.obsidian`）内の `plugins` に `folder-limit-enhanced` フォルダを作成します。
3. ビルド済みの `main.js`、`manifest.json`、`styles.css` を作成したフォルダにコピーします。
4. Obsidianを再起動し、「設定」→「コミュニティプラグイン」で **Folder Limit Enhanced** を有効にします。

ソースからビルドする場合は、Node.js 20以降を用意し、開発用の `folder-limit-enhanced` ディレクトリで次を実行します。ビルドは同じディレクトリに `main.js` を生成します。同梱の `manifest.json` と `styles.css` を合わせた3ファイルがインストール用です。

```sh
npm ci
npm run build
```

## 設定

「設定」→「Folder Limit Enhanced」で変更できます。

| 設定 | 初期値 | 動作 |
| --- | --- | --- |
| 表示件数 | 20 | フォルダごとに初期表示するファイル数。1以上の整数を指定します。 |
| フォルダ名の横に件数を表示 | ON | Vaultが認識する直下ファイルの総数を表示します。一覧で非表示の拡張子も含みます。 |
| サブフォルダの件数も併記 | ON | 直下のファイル数と、配下すべてのファイル・フォルダの件数を併記します。OFFでは直下のファイル数だけ表示します。 |
| 残り件数を表示 | ON | OFFの場合は省略中に `▼ 全件を表示` と表示します。 |
| 展開・省略ボタンを表示 | ON | OFFでも上限は適用されます。上限を超えるフォルダの右クリックメニューで切り替えられます。 |
| 展開状態を記憶 | ON | 展開状態をフォルダごとに保存します。OFFの場合は現在のセッション内だけ保持します。 |

設定と展開状態は、本プラグインの `folder-limit-enhanced/data.json` に保存されます。名前変更・移動したフォルダは展開状態を引き継ぎます。標準のフォルダ開閉は引き続きObsidianが管理します。

## 実装と制約

- ビューの取得、Vaultイベント、右クリックメニュー、設定保存にはObsidianの公開Plugin APIを使います。公開APIでは標準ツリーの仮想リストを加工できないため、ファイルを並べる内部メソッドと仮想ツリーにビュー単位で接続します。対応する内部構造を見つけられない場合は、表示制限を適用しません。Obsidianの更新で内部仕様が変わった場合は、プラグイン側の更新が必要になることがあります。[Obsidian Plugin API](https://github.com/obsidianmd/obsidian-api) · [Obsidian 1.15.1](https://github.com/obsidianmd/obsidian-releases/releases/tag/v1.15.1)
- 標準の並び順、既存のファイル行、アイコンのDOM、イベントを使います。非対応の拡張子は、Obsidianの「すべてのファイル拡張子を認識」が有効な場合など、標準ツリーに表示されるときに件数に含まれます。クリック時は該当フォルダの仮想リストだけを更新します。ファイルの変更や並び順の変更は、標準の再ソートに合わせて反映されます。
- 省略される行の選択は解除します。展開・省略した後は末尾の切り替えボタンへフォーカスを戻します。省略中のファイルに標準の「ファイルエクスプローラーで表示」やインラインの名前変更が明示的に適用された場合は、その親フォルダを全件表示にします。自動表示中に省略されたファイルを表示するには、親フォルダのボタンか標準の表示コマンドを使います。
- 標準エクスプローラーの絞り込み検索が動作している間は、一時的に件数制限を解除します。検索を終了すると、フォルダごとの展開状態が再適用されます。
- 元版 Folder Limit 1.0.7 も同じ並び替え処理に介入するため、同時使用すると先に省略されたファイルの件数や表示が食い違う可能性があります。`folder-limit` が有効だと検出した場合、Enhancedは表示制限を停止して通知します。元版の設定や有効状態はユーザーが管理します。元版は0BSDで公開されており、競合調査で実装を確認しました。Enhancedは独自実装です。[Folder Limit 1.0.7の実装](https://github.com/naggischnulu/obsidian-folder-limit/blob/1.0.7/src/main.ts) · [ライセンス](https://github.com/naggischnulu/obsidian-folder-limit/blob/1.0.7/LICENSE)

## Folder Countsから切り替える場合

件数バッジをEnhancedに統一する場合は、Folder Countsを手動で無効にしてください。Enhancedのバッジにカーソルを置くと対象フォルダのパスと件数の内訳を確認できます。直下のうち一覧で表示できるファイル数が直下の総数と異なるときは、その内訳も表示されます。単語数や容量の集計はFolder Counts側の機能です。

File Filterのフォルダビューでは、そのビューの範囲内にあるフォルダの切り替えボタンだけが表示されます。親フォルダに戻ると、その親のボタンを操作できます。

## 元のFolder Limitに戻す

1. Obsidianの「設定」→「コミュニティプラグイン」で **Folder Limit Enhanced** を無効にします。
2. **Folder Limit** を再度有効にします。元の設定はそのまま利用できます。ツリーの表示が残る場合はObsidianを再起動します。

## 検証結果

TypeScriptの型チェックとビルドは成功しました。Chromium上でビルド済みコードと模擬ファイルエクスプローラーを使い、以下を確認しました。CSSの確認にはObsidian 1.15.1およびMinimal 9.1.4のスタイルを使用しました。Obsidian 1.15.1の仮想描画処理を取り出したChromiumのテストでも、100件の一覧を20件→全件→20件へ切り替えたときのスクロール領域と、無効化後の100件復元を確認しました。プラグインをObsidianへインストールしての確認は未実施です。

| 項目 | 確認した内容 |
| --- | --- |
| 10件・20件・21件・100件 | 10件・20件ではボタンがなく、21件では残り1件、100件では残り80件と表示 |
| 展開・再省略 | クリック、Enter、Spaceで切り替え |
| 階層とフォルダごとの状態 | 親子・兄弟フォルダの独立した動作、標準の開閉を模した動作、複数ペイン間での状態共有 |
| ファイル変更・境界 | 追加、削除、移動、名前変更に合わせた件数更新。標準順を模した昇順・降順で20件の境界を確認 |
| Minimalのライト・ダーク | 両モードの文字色、ボタンの最小高と折り返し、背景を付けない太字のバッジを確認 |
| 既存の行と操作 | 模擬アイコンを持つDOMとイベントの維持、選択の維持と省略される行の選択解除を確認 |
| 設定と無効化 | 保存データからの再読み込み、記憶OFF、ボタン非表示時のメニュー、無効化時の標準リスト復元 |
| 元版との競合 | 模擬プラグインを後から有効・無効にして、Enhancedの制限停止と復帰を確認 |
| フォルダ件数バッジ | 直下21件のうち表示対象が16件でも、バッジは21件。全件表示と再省略で総数を維持し、追加・移動・削除で更新 |

| サブフォルダの件数 | 複数階層のファイル・フォルダ数、追加・移動・削除時の更新、設定OFF時の直下件数表示と再読み込みを確認 |
